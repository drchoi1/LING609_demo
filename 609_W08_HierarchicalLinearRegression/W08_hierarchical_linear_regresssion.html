I choose a lognormal likelihood because RTs are strictly positive and typically right-skewed. And I specify a Normal(6, 1) prior for the intercept, reflecting a plausible baseline median RT of approximately 403 ms (=exp(6)) while allowing uncertainty about the intercept.

fit_RT <- brm(rt ~ 1 + type_c + (1 + type_c | subj) + (1 + type_c | item),
              data = gw.n2,
              family = lognormal(),
              prior = c(
                prior(normal(6, 1), class = Intercept),
                prior(normal(0, 0.1), class = b, coef = type_c),
                prior(normal(0, 1), class = sigma),
                prior(normal(0, 1), class = sd),
                prior(lkj(2), class = cor)
              ))

sample_b_post <- as_draws_df(fit_RT)$b_type_c

samples <-
  tibble(sample = c(sample_b_post, sample_b_prior),
         distribution = c(rep("posterior", N), rep("prior", N)))
ggplot(samples, aes(x = sample, fill = distribution)) +
  geom_density(alpha = 0.5)

A posterior shifted away from zero = the data have updated beliefs; A narrower posterior = the data have reduced uncertainty about β.

Exercise 3

The posterior mean effect of extraction type was −0.056 (95% credible interval: [−0.147, 0.037]). Since ORCs were coded as +0.5 and SRCS as -0.5, this corresponds to ~5.4% shorter RTs for ORCs than SRCs (the negative coefficient = the positive factor, ORC, gets smaller RTs compared to the negative factor, SRC),contrary to Gibson and Wu’s prediction. However, CrI includes zero, meaning there is a visible uncertainty about the direction of the effect. Thus, the model does not provide convincing evidence that ORCs are read more slowly(/fastly) than SRCs.
