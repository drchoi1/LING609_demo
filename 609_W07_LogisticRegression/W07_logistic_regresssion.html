The posterior mean odds ratio for centered set size was 0.835 (95% credible interval: [0.711, 0.977]), indicating that each additional item in the set was associated with approximately 16.5% lower odds of successful recall.

mean(beta_samples < 0)

Given the observed data and the model, there is a 98% posterior probability that increasing set size decreases the odds of successful recall.

Exercise 3

# Center the new set size using the original data mean
c_set_size_10 <- 10 - mean(df_recall$set_size)

# Predicted probability for each posterior draw
pred_10 <- plogis(alpha_samples + beta_samples * c_set_size_10)

# Posterior mean and 95% CrI
c(mean = mean(pred_10), quantile(pred_10, c(0.025, 0.975)))
     mean      2.5%     97.5% 
0.7220776 0.5274197 0.8704133

The posterior mean predicted recall accuracy at set size 10 is 72.3% (95% CrI: [53.3%, 88.1%]). However, I have limited confidence in this prediction because set size 10 was never tested. The estimate assumes that the effect of increasing set size remains constant on log-odds scale. The relatively wide CrI (~35%p) also indicates increased uncertainty about the predicted accuracy.
